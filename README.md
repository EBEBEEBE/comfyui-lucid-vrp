# LuCiD VRP — Visual Regional Painter

LuCiD VRP brings image loading, layered editing with LuCiD Canvas, Anima regional prompting, and experimental MOSS-Image layout prompting to ComfyUI.

[Read the full documentation and view example workflows on GitHub](https://github.com/EBEBEEBE/comfyui-lucid-vrp/blob/main/README.md).
