## English

**LuCiD VRP** (Visual Regional Painter) brings image loading, layered editing, **Anima regional prompting**, and **MOSS-Image layout prompting** together in ComfyUI. Built with **image-to-image (img2img) workflows** in mind, it helps you compose, edit, and describe your next generation through a responsive visual interface.

[Read the full documentation and view example workflows on GitHub](https://github.com/EBEBEEBE/comfyui-lucid-vrp/blob/main/README.md).

## 简体中文

**LuCiD VRP**（Visual Regional Painter）是一套 ComfyUI 自定义节点，集图像加载、图层编辑、**Anima 区域提示词**和 **MOSS-Image 布局提示词**于一身。它主要为**图生图（img2img）工作流**设计，让你直接在 ComfyUI 中完成构图、图像编辑和提示词设置。

[详细文档和示例工作流请到Github查看。](https://github.com/EBEBEEBE/comfyui-lucid-vrp/blob/main/docs/zh-Hans/README.md)。

## 繁體中文

**LuCiD VRP**（Visual Regional Painter）是一套 ComfyUI 自訂節點，整合了圖像載入、圖層編輯、**Anima 區域提示詞**與 **MOSS-Image 畫面配置提示詞**。它主要針對**圖生圖（img2img）工作流程**設計，讓你直接在 ComfyUI 裡完成構圖、圖像編輯與提示詞設定。

[請前往 GitHub 閱讀完整文件，並查看工作流程範例。](https://github.com/EBEBEEBE/comfyui-lucid-vrp/blob/main/docs/zh-Hant/README.md)。

## 日本語

**LuCiD VRP**（Visual Regional Painter）は、画像の読み込みやレイヤー編集、**Anima の領域プロンプト**、**MOSS-Image のレイアウトプロンプト**を ComfyUI で使えるようにするノードセットです。**img2img**（画像から画像を生成するワークフロー）を中心に設計しており、構図作りから画像編集、プロンプトの設定まで、画面を見ながらスムーズに進められます。

[詳しいドキュメントとワークフロー例は GitHub をご覧ください。](https://github.com/EBEBEEBE/comfyui-lucid-vrp/blob/main/docs/ja/README.md)。
